# Student-Performance-Classifier-python-
Machine Learning project for predicting student performance using Random Forest and Streamlit.


## Project Overview
This project predicts student performance using Machine Learning techniques and classifies students into four categories:

- Excellent
- Good
- Average
- Poor

## Features
- Student performance prediction
- Random Forest Machine Learning model
- Interactive Streamlit web application
- Performance analytics dashboard
- Feature importance visualization

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- Streamlit
- Plotly

## Dataset Features
- Study Hours
- Attendance
- Marks
- Assignment Score

## Model Used
Random Forest Classifier
